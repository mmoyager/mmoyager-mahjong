## 4. 为什么到顶了

三条独立的正面测量，而不是推测：

1. **加信息**（第 31/32 轮）：新特征、更新鲜的数据 → 零；
2. **加容量**（第 33 轮）：参数 +54% → 训练损失降 7%、验证准确率不变、棋力略降；
3. **加训练量**（第 26/28 轮）：数据 ×3.8、轮数 ×2 → 零或略负。

而第 35–37 轮给出了机制上的解释：**学生在它偏离老师的地方更好**。
它只复现老师 13.7% 的"碰"，放銃率比老师低 0.015；把这两类决策分别拽回老师
（加权 10×）分别让棋力掉 **1665** 与 **176~326** 分。
换句话说，**它比老师高 321 分的主要来源正是这些"没学会"的偏离** ——
所以在"更严格地模仿"这个方向上已经没有剩余空间。

## 5. 怎么跑、怎么测（操作手册）

```bash
# 长期训练循环（可中断、可续跑；每轮评测可回滚）
.venv/bin/python -u python/trainer/loop.py --resume --forever --dagger-loop --search-modes \
  --primary-spec efficiency-v2 --yardstick2 efficiency --eval-games 9600 --accept-margin 60 \
  --confirm-runs 2 --early-stop-slack 100 --bootstrap-lr 3e-4 --bootstrap-records 900000 \
  --bootstrap-epochs 4 --bootstrap-data data/selfplay/im-v12.bin --value-coef 0.25 \
  --entropy-coef 0.005 --max-records 400000 --threads 4 --accept-on direct --abs-every 5

# 单次评测（配对固定种子；--a/--b 两侧都可以直接放权重文件）
./target/release/mmj-eval --a data/checkpoints/ck-ab.bin --b efficiency-v2 --games 9600 --seed 4242

# 模仿质量诊断（按决策类别 / 按危险度切分，会暴露聚合保真度掩盖的问题）
.venv/bin/python python/trainer/diagnose_calls.py data/checkpoints/ck-ab.bin data/selfplay/im-v12.bin
```

**测量纪律**（这些规则都是被事故换来的）：

* 测吞吐/时间时**先停掉循环**（否则数字能差 2~7 倍）；不能停就**交替测**新旧两边；
* 判断"某改动更好"必须**在同一批里重测在位者**（第 20 轮曾用陈旧基线把噪声读成 +300）；
* 从头训练的副本间波动 sd 60~124（激进配方更高），**每臂至少 3 副本**；
* **聚合保真度会骗人**：单一 top-1 把"完全没学会的一类决策"藏在 0.969 里，要按类别切分；
* 生成的数据必须**逐字节可复现**：改编码器/核函数后，用改动前后的二进制在同一 seed 上
  生成并比对 md5（行为类改动允许不一致，但必须先说清楚**为什么**该不一致，并给出差异幅度）。

## 6. 还没试、或试不了的方向

| 方向 | 状况 |
|---|---|
| **i8 量化权重** | 未试。前向是"按权重字节数"受限的（半精度已拿 +8%），i8 还能再砍一半，但需要量化激活，收益与精度风险并存 |
| **搜索（1-ply 以上）** | 试不了：价值头的真实拟合度只有 R²≈0.11（预测标准差只有目标的 36%），用它的期望得失做搜索没有信息量 |
| **更快的 shanten** | 未做。手牌评估占生成/评测的 40~55%（`regular_shanten` 单次约 0.9 µs，被调用数十万次/局）；换平表或更好的缓存是唯一还没试过的吞吐项 |
| **真实人类对手** | 按约定不录入人类牌谱，所以"是否逼近人类水平"只能靠风格统计对照（第 34 节），无法直接测 |
| **新信息通道** | 已试两条（序列读、对手立直后舍牌），都是零；要再找一条需要新的局面知识，而不是新的编码方式 |
